## How to Test / Quick Start

### 1. Opening the Main Scene
* Open the **`Assets/_Project/Scenes/Main.unity`** scene to review and test the project.

### 2. Unity 6 Package Compatibility Warning
When opening the project in **Unity 6**, you may encounter a **"Missing Signature"** error/warning dialog for the following packages:
* **Extenject**
* **UniTask**
* **UniRx**

**Solution:** This is a known compatibility notice. Simply click **"Continue"** to bypass the warning and load the project normally.
